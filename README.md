# Modazerina

**Her kadına özel, zerin bir dokunuş.**

Modazerina, tesettür giyimde modern zarafeti, zamansız şıklığı ve **özel dikim anlayışını** bir araya getiren bir markadır.  
Her parça, kadının duruşuna ve tarzına özel olarak tasarlanır.

Bu repository, Modazerina’nın yakında yayına alınacak resmi web sitesi için hazırlanmıştır.
